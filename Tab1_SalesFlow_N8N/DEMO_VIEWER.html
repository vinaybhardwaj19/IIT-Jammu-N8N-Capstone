⚡ How to Import & Run in N8N
Follow these steps to deploy SalesFlow AI in any N8N instance
1
Open N8N
Launch N8N at localhost:5678 or your cloud instance. Create a new workspace.
2
Import JSONs
Workflows → + New → ⋮ Menu → "Import from File" → Select each .json file from workflows/
3
Set Credentials
Add PostgreSQL, OpenAI API key, Gmail OAuth2, Google Calendar, Drive, Sheets, Slack token
4
Create DB Tables
Run the SQL from README.md to create leads, sales_reps, follow_ups tables + seed data
5
Activate & Test
Activate each workflow. Use the curl commands from README to send test webhook requests
# Test Workflow 01 — Lead Capture (run this in terminal)
curl -X POST https://your-n8n.app/webhook/capture-lead \
  -H "Content-Type: application/json" \
  -d '{"full_name":"Priya Sharma","email":"priya@techcorp.in","company":"TechCorp","industry":"SaaS","budget":"$2000/month","source":"LinkedIn"}'
